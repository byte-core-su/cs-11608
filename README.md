# 資訊科技闖關系統

八年級資訊科技的遊戲化闖關學習網站，給各校老師搬回去自己用。
四門課，**只需要一個 Firebase 專案**——不需要伺服器、AI 金鑰，學生也不需要 Google 帳號。
程式設計想要**自動給作品星**的話，再加一支 Apps Script（選用，約 10 分鐘，見 `gas/README.md`）。

| 課 | 頁面 | 星數 | 內容 |
|---|---|---|---|
| ⚖️ 資訊倫理 | `course/cyberethics.html` | 30 | 網路禮儀、PAPA、著作權、個資法，10 關測驗 |
| 🧠 運算思維挑戰 | `course/thinking.html` | 20 | 10 道外部謎題，解完交通關截圖 |
| 🐱 程式設計（Scratch） | `course/flowchart.html` | 30／60 | 10 個單元，**全部開放**：排流程圖 → 寫 Scratch；前導「清單學習機」與簡譜教材。有接自動評分是 60（多了作品星 10×3） |
| 💡 智慧家居機電專題 | `course/5016b.html` | 0 | 五節課的模擬實驗室（感應、換算、調速、混色、專題） |
| 🌟 晨星勇者 | `course/morningstar.html` | 0 | 程式設計十關都完成後開放的獎勵遊戲 |
| 🏆 闖關排行賽 | `course/arena.html` | 0 | 資訊倫理全部題目大亂鬥，答對升級答錯降級、全年級排行（**選用**，要接 Apps Script） |

## 登入方式：學號＋六位數驗證碼

參考 [byte-core-su/cs-11507](https://github.com/byte-core-su/cs-11507) 的做法：

- **學生**：輸入學號和六位數驗證碼。**第一次登入**時，名冊裡有這個學號、還沒設定過，系統就請他自己設定一組驗證碼。
- **老師**：Firebase 裡建立的「電子郵件／密碼」帳號（`config.js` 的 `SCHOOL.TEACHER_EMAIL`）。
- **忘記驗證碼**：老師在教師後台「👥 學生帳號」查看或重設。

背後是 Firebase 的 Email／密碼登入：學生帳號的 email 是系統自己組的
`{學號}@students.{專案 ID}.firebaseapp.com`（不是真的信箱），密碼就是驗證碼。
比對密碼是 Firebase 自己做的，網頁從頭到尾不讀驗證碼。

> **和 cs-11507 不一樣的一點**：cs-11507 把驗證碼存在名冊裡，而名冊是登入前就要讀的
> ——等於任何人都讀得到別人的驗證碼。這裡把驗證碼放在 `codes/{學號}`，**只有老師讀得到**；
> 名冊只留一個「設定過沒有」的旗標（`hasCode`）。

⚠️ **已知風險**（cs-11507 也有）：還沒設定驗證碼的學號，任何知道學號的人都能搶先設定。
被搶先的學生會看到「這個學號已經有人設定過驗證碼了」。處理方式：
Firebase Console → Authentication 刪掉那個帳號 → 驗證碼管理頁按「清除設定」→ 請學生重新設定。
**建議第一堂課就讓全班當場設定好。**

⚠️ 學生登入狀態會留在瀏覽器裡（關掉分頁不會登出）。電腦教室**沒有還原卡**的話，
請提醒學生下課按「登出」。老師的登入只留在那一個分頁，不會帶到學生頁。

## 移植步驟

### ① 建 Firebase 專案（免費的 Spark 方案就夠）

1. [Firebase Console](https://console.firebase.google.com/) → 新增專案。
2. **Authentication → 登入方式**，開啟兩個：
   - **電子郵件／密碼**（學生和老師都靠它）
   - **匿名**（學生登入前要先查名冊，確認有這個人）
3. **Authentication → 使用者 → 新增使用者**：建立你的**教師帳號**（信箱＋密碼）。
   ⚠️ 一定要比學生**先**建好——不然理論上有人可以搶先用你的信箱註冊。
4. **Firestore Database → 建立資料庫**（正式模式，地區選 `asia-east1` 台灣）。
5. **專案設定 → 一般 → 你的應用程式 → 新增網頁應用程式**，把出現的 `firebaseConfig` 抄下來。

### ② 改 `course/config.js`（標【必改】的地方）

```js
SCHOOL: {
  NAME: '你的學校',
  GRADE: '八年級',
  SID_PATTERN: '^\\d{7}$',          // 學號格式
  SID_HINT: '7 位數字',
  TEACHER_EMAIL: 'you@example.com', // ① 第 3 步建的教師帳號，一律小寫
},
TERM_START: '2026-08-31',            // 第 1 週的星期一
FIREBASE: { ... },                   // ① 第 5 步抄下來的那一段
```

### ③ 改 `firestore.rules` 最上面三行，然後發布

```
function TEACHER_EMAIL() { return 'you@example.com'; }
function DOMAIN()        { return '@students.你的專案ID.firebaseapp.com'; }
function TERM()          { return '11501'; }
```

整份貼到 **Firestore Database → 規則**，按**發布**，親眼看到「已發佈」才算數。
⚠️ 只改檔案、沒按發布，線上什麼都不會變——症狀是「登得進去，但進度存不起來」，而且沒有任何錯誤訊息。

### ④ 放上網

整個資料夾就是網站，任何靜態網站空間都可以（GitHub Pages 最簡單）。
放好之後回 Firebase：**Authentication → 設定 → 授權網域**，加上你的網址（例如 `你的帳號.github.io`）。

### ⑤ 開學前

1. 開 `teacher.html`（教師後台），用教師帳號登入。
2. **👥 學生帳號 → 匯入名冊**：一行一位 `學號,班級,座號,姓名`，從 Excel 選四欄複製貼上也可以。
   ⚠️ 名冊沒建好，學生**登不進去**（安全規則會擋）。
3. **📊 成績總覽 → 上課日設定**：填各班的上課時段（本週成績卡用它判出席）。
4. 第一堂課：學生開 `index.html`，輸入學號和自己想用的六位數字，完成設定。

### ⑥（選用）程式設計自動評分

部署 `gas/grader.gs`（步驟見 `gas/README.md`），把網址貼到 `config.js` 的 `GRADER_URL`，
再到教師後台「📗 評分範本」逐關上傳**參考解答**和**空白範本**兩個 `.sb3`。
學生在程式設計頁上傳作品，系統和範例逐塊比對（積木 50、位置 30、設定值 20），給 0～3⭐。

同一個 Apps Script 也順便做兩件事（都是**下課後老師打開後台時才比對**，上課時不比對、不拖慢連線）：
- **👯 相同作品**：「🐱 作品評分」列出交了同一個檔案、或拿別人的檔案改一點點再交的學生，可以取消其中某位的那一關成績。
  取消後再交同一份會被擋下，自己重做的照常評分。
- **🧠 通關截圖**：Apps Script 的指令碼屬性設了 `DRIVE_FOLDER_ID`，運算思維過關時截圖會在背景存到那個雲端硬碟資料夾，
  後台「🧠 通關截圖」看得到每一關的截圖，同一張圖交兩次以上會標出來。

### ⑦（選用）資訊倫理 闖關排行賽

和自動評分**同一個 Apps Script**，不用另外部署。接好 `GRADER_URL` 之後：
教師後台「🏆 排行賽」→ 按一次**匯入題庫**（從 `content/ethics.js` 抽出 141 題）。
學生的闖關基地就會多一張「🏆 資訊倫理 闖關排行賽」卡片（資訊倫理 10 章全部通關才解鎖）。
不想開：`config.js` 的 `ARENA` 改成 `false`。
⚠️ 改了 `ethics.js` 的題目，後台會顯示「網站上的題目改過了」，再按一次「重新匯入」。

### ⑧（選用）繳交審核讀 Classroom

學生在 Classroom 交流程圖圖片，老師在後台「📥 繳交審核」看過後給 +1⭐。
部署 `gas/classroom.gs`（**另一個** Apps Script 專案，要用老師的**學校** Google 帳號，步驟寫在檔案開頭，約 5 分鐘），
把網址貼到 `config.js` 的 `CLASSROOM.GAS_URL`，審核頁就能直接列出誰交了、點開圖片。
通行碼（`QUERY_KEY`）**不要**寫進 `config.js`——在審核頁輸入一次，只存在那台電腦。
不部署也能用：審核頁照樣能給分，只是要自己開 Classroom 看。

## 設計取捨

沒有伺服器、沒有 AI，所以幾個地方是這樣做的：

| 地方 | 做法 |
|---|---|
| 🧠 運算思維過關 | **自行回報**：選好通關截圖（檔名要認得出是哪一關）按送出就記錄，系統不判讀截圖內容。有接 Apps Script 並設了雲端硬碟資料夾的話，截圖會在背景存給你看（送不上去也不影響過關）；沒接就不上傳——需要時請學生當場打開通關畫面給你看 |
| 🐱 程式設計開放順序 | **十關全部開放**，順序學生自己決定 |
| 🐱 作品星 | **有接 Apps Script**：和你的參考解答逐塊比對（積木、位置、設定值），3⭐ 要和範例一致。**沒接**：`.sb3` 交到你指定的地方，作品星不計 |
| 💡 5016B 開放式作答 | 瀏覽器裡用關鍵字判定 |

## 教師管理後台

所有教師功能集中在 `teacher.html`（版型參考 cs-11507）：**登入一次，上方一排分頁切換**。

| 分頁 | 做什麼 |
|---|---|
| 📊 成績總覽 | 全班星數、學生個別進度圖、出席；工具列有**即時看板、上課日設定、每週評分（可匯出 CSV）** |
| 🐱 作品評分 | 逐班、逐關看作品星與分數（綠 3⭐／黃 2⭐／紅 0⭐）；點一格看最近送出時間、打開備份的作品、**手動調整星數**（標 ✍️）；匯出 CSV。**👯 相同作品**：全年級比對，可以**取消成績**（標 🚫，可撤銷） |
| 🧠 通關截圖 | 全班 × 10 關的運算思維通關截圖（📷），點開看圖、開雲端硬碟原檔；**👯 相同截圖**標出來 |
| 📗 評分範本 | 各關上傳參考解答／空白範本；「試評」一份作品看會拿幾分 |
| 📥 繳交審核 | 看過 Classroom 的流程圖圖片後按「給分」（+1⭐），或退件請學生補交 |
| 📈 題目分析 | 資訊倫理哪幾題全班一直錯 |
| 🏆 排行賽 | **匯入題庫**；全部參賽者的排名（班級、姓名、用時、離開／超時、像腳本的場次）；學生斷線白白用掉一次機會時**退回 1 次**（有接 Apps Script 才出現） |
| 🔍 可疑紀錄 | 沒有作答過程、每題都在 1 秒內的測驗紀錄 |
| 👥 學生帳號 | **匯入名冊**（學號、班級、座號、姓名）、刪除學生、查看／重設／清除驗證碼 |

「🐱 作品評分」「📗 評分範本」「🧠 通關截圖」只在有接 Apps Script（`GRADER_URL`）時出現。

★ 每個分頁其實是一支獨立的頁面（`course/dashboard.html`、`shared/*.html`），放在後台裡顯示。
  好處是一頁出錯不會拖垮整個後台；單獨打開也能用（會多一條「← 回教師端」）。

⚠️ 老師的登入只留在那一個瀏覽器分頁——關掉就要重登。這是刻意的：學生也用同一個 Firebase 專案，
老師的身分留在整個瀏覽器，下一個開學生頁的人會被當成老師。

**資料庫裡有什麼**（`TERM` 預設 `11501`，換學期改 `config.js` 和規則的 `TERM()`）

| 集合 | 內容 | 誰能讀寫 |
|---|---|---|
| `roster/{學號}` | 姓名、班級、座號、`hasCode` | 老師；學生只能單筆讀 |
| `codes/{學號}` | 學生的驗證碼 | 只有老師（學生第一次設定時寫一次） |
| `{TERM}-progress/{學號}` | 各課星數、闖關紀錄、出席；作品的指紋（`unitPrint`）、取消紀錄（`revoked`）、通關截圖連結（`thinking.shots`） | 老師；學生只能寫自己的，而且星數、指紋、取消紀錄、截圖連結寫不動 |
| `{TERM}-config/*` | 成績簿、上課日 | 老師（上課日學生可讀） |
| `{TERM}-grader/criteria` | 各關的參考解答、空白範本（虛擬碼） | **只有老師**（Apps Script 用老師的身分讀） |
| `{TERM}-grader/arena_bank` | 排行賽題庫（從 `ethics.js` 匯入） | 只有老師 |
| `{TERM}-arena-board/{學號}`、`{TERM}-arena-runs/{場次}` | 排行賽最佳成績、今天用了幾次；每一場的紀錄 | 只有 Apps Script 寫；老師可讀；學生讀不到（看排行走 Apps Script，只有前 30 名的學號） |
| `{TERM}-arena-days/{日期}` | 當天的難度分級 | 只有 Apps Script |
| `artifacts/comp-think-app/…/progress` | 運算思維過關紀錄 | 登入者可讀；只能寫自己的 |

⚠️ 運算思維那一份**不分學期**。換學年要清空的話，到 Firestore Console 刪掉那個集合。
